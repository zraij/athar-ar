# athar-ar — صفحات الواقع المعزز | أثر أكاديمي

صفحات واقع معزز عبر المتصفح (WebAR) لكتب أثر أكاديمي: يوجّه الطالب كاميرا الهاتف نحو صفحة الكتاب فيظهر مجسّم ثلاثي الأبعاد تفاعلي. لا يحتاج تثبيت تطبيق.

- الرابط: https://zraij.github.io/athar-ar/
- الخلية الحيوانية: https://zraij.github.io/athar-ar/cell/
- معاينة بدون كاميرا: https://zraij.github.io/athar-ar/cell/?preview

## البنية
```
lib/      مكتبات مشتركة: three.js (r152) + MindAR 1.2.5 — لا تحدّث three فوق 0.160 لأن MindAR يحتاج sRGBEncoding
fonts/    خط Cairo
cell/     درس الخلية الحيوانية
  index.html  الواجهة
  app.js      الكاميرا والتتبع واللمس والأسماء
  cell.js     نموذج الخلية ثلاثي الأبعاد (مبني بالكود) + الأسماء والوظائف
  target.png  صفحة الكتاب (الهدف 0)
  target2.png صفحة ملزمة أثر أكاديمي (الهدف 1)
  targets.mind  بصمة الصفحتين للتتبع (هدفان)
```

## إضافة درس جديد
1. انسخ مجلد `cell` باسم جديد.
2. ضع صورة صفحة الكتاب `target.png` (يفضّل غنية بالتفاصيل والنصوص).
3. حوّلها إلى `targets.mind` بأداة MindAR Image Target Compiler.
4. ضع النموذج ثلاثي الأبعاد (ملف .glb أو نموذج بالكود) وعدّل الأسماء والوظائف.
5. أضف عنصراً في مصفوفة `TARGETS` في app.js (موضع مركز الرسم x,y وحجم المجسم s) لكل صفحة هدف.
6. أضف بطاقة الدرس في `index.html` الرئيسي.

ملاحظة: الكاميرا تعمل فقط على رابط https (مثل GitHub Pages).

## التحكم بالمجسم
- السحب بإصبع واحد يدوّر المجسم 360° بكل الاتجاهات (يمين/يسار وفوق/جوة) بدون قفل محاور، مع عطالة خفيفة.
- «أفقي» دوران تلقائي حول المحور العمودي، و«عمودي» قلب تلقائي فوق وجوة.
- «افصل المجسم» يطلع الخلية من الورقة لنص الشاشة حتى تدوّرها براحتك بدون ما تضيع الصفحة من الكاميرا.
- معاينة صفحة الملزمة بدون كاميرا: `cell/?preview&page=mulzama`
